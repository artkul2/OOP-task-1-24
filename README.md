# Оптимизатор галереи фотографий (консольное приложение)

Консольное приложение, которое умеет:
- **удалять одинаковые (дублирующиеся) фотографии**;
- **распределять фотографии по каталогам** по сезонам года, по месяцам или по форматам файлов;
- **обрабатывать метаданные**.


## Запуск

Используйте скрипты из папки `scripts`:

```bat
scripts\run-demo.bat    :: компиляция + консольное демо
scripts\run-tests.bat   :: компиляция + запуск 26 юнит-тестов
```

JUnit-jar (`lib/junit-platform-console-standalone.jar`) уже лежит в репозитории, скачивать его не нужно. Требуется только установленный JDK 17+ (проверка: `java -version`).
